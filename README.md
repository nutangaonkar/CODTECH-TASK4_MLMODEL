# CODTECH Internship – Task 4
## Machine Learning Model Implementation

This project implements a simple Machine Learning classification model using Python.  
The model is trained on the Iris dataset to predict the species of flowers based on their measurements.

### Technologies Used
Python, Machine Learning, scikit-learn, Jupyter Notebook

### Required Libraries Command
pip install scikit-learn notebook

### How to Run the Project
1. Open Anaconda Prompt.
2. Navigate to the project folder.
3. Start Jupyter Notebook:
   jupyter notebook
4. Open the file `ml_model.ipynb`.
5. Run all cells to see the output.

### Model Description
The Iris dataset is used in this project. The dataset is split into training and testing data.  
A Logistic Regression model is trained and evaluated using accuracy score.

### Output
The notebook displays the model accuracy after training and testing.
